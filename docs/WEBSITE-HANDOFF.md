เว็บไซต์ภาษาไทยสร้างตามภาพต้นแบบที่ผู้ใช้ให้ โดยปรับการจัดวางให้ใช้งานได้ทั้งเดสก์ท็อปและมือถือ รูปแบบ ฟอนต์ และการแสดงสีอาจต่างกันตามขนาดจอและเบราว์เซอร์

## ฟังก์ชันที่ส่งมอบ

- หน้าแรกมีห้องตัวอย่าง 7 แบบ สีพื้น 6 แบบ ตัวกรองโทนสี แกลเลอรี ปุ่มห้องก่อนหน้า/ถัดไป และภาพเต็มจอ
- สีพื้นเรียงเป็น Light Natural Oak, Warm Oak, Honey Oak, Classic Oak, Grey Oak และ Walnut Brown พร้อมรหัส CP-101 ถึง CP-106
- ส่วนเปิดหน้าแรกเป็น Motion Scrolling 12 ขั้น: ตรึงฉากไว้ขณะเปลี่ยนสีพื้นห้องและวัสดุ WebGL พร้อมกัน จากนั้นขยายชิ้นตัวอย่าง แสดงความหนา 5 MM และอธิบายโครงสร้างทีละชั้น ก่อนปล่อยหน้าให้เลื่อนลงต่อ
- แผ่นตัวอย่าง WebGL หมุนด้วยการลากเมาส์ระหว่างชมเรื่องราวได้ มีสไลเดอร์แยกชั้น ปุ่มกลับมุมเริ่มต้น และภาพเต็มจอ
- ภาพห้องมีการเปลี่ยนสีเฉพาะพื้นที่ที่กำหนดไว้ เปรียบเทียบก่อน/หลัง และเลือกภาพเต็มหรือรายละเอียดผ่านภาพย่อ
- อัปโหลดภาพ JPG, PNG หรือ WebP ขนาดไม่เกิน 20 MB แล้วเลือก 4 มุมของพื้นซึ่งไม่มีเฟอร์นิเจอร์บัง ภาพประมวลผลภายในเบราว์เซอร์
- เลือกมุมด้วยเมาส์ หรือใช้ปุ่มลูกศรและ Enter; Backspace ลบจุดล่าสุด และ Escape เริ่มเลือกใหม่เมื่อโฟกัสอยู่บนภาพ
- มีเมนูมือถือ หน้าต่างข้อมูลบริการและติดต่อ ป้ายสำหรับโปรแกรมอ่านหน้าจอ และการควบคุมด้วยแป้นพิมพ์
- เครื่องคำนวณเปลี่ยนเกรด กรอกพื้นที่และปรับค่าติดตั้งได้ พร้อมตรวจข้อมูลและอัปเดตผลรวม
- แบบฟอร์มใบประมาณราคาสร้างไฟล์ HTML ดาวน์โหลดได้ เปิดหน้าต่างพิมพ์/บันทึก PDF ผ่านเบราว์เซอร์ หรือเตรียมอีเมลฉบับร่างพร้อมรายละเอียด

## ลำดับ Motion Scrolling หน้าแรก

ส่วนเปิดหน้าใช้การเลื่อนหน้าปกติร่วมกับฉากแบบ sticky ไม่มีการดักวงล้อเมาส์เพื่อล็อกหน้า ระยะหนึ่งขั้นเท่ากับ **0.78 เท่าของความสูงจอ** การเลื่อนช้าจะแสดงจังหวะเปลี่ยนต่อเนื่อง และเลื่อนย้อนกลับได้ตามตำแหน่งเดิม สีพื้นในภาพห้องและวัสดุบนชิ้น 3D ใช้ค่าการเปลี่ยนชุดเดียวกันและเตรียมวัสดุทั้งหกไว้ก่อนเริ่ม

| ขั้นที่แสดงบนหน้า | เนื้อหา |
| --- | --- |
| 01–06 | Light Natural Oak → Warm Oak → Honey Oak → Classic Oak → Grey Oak → Walnut Brown; พื้นห้องและชิ้น WebGL เปลี่ยนพร้อมกัน |
| 07 | ขยายชิ้นตัวอย่างและเข้าสู่มุมด้านข้างตื้น แสดงเส้นบอกความหนารวมของแผ่นที่ประกบอยู่ พร้อมข้อความ **5 MM** |
| 08 | เริ่มแยกชั้นและเผยเส้นชี้ **Wear Layer — ชั้นเคลือบป้องกันผิว** |
| 09 | เพิ่มรายละเอียด **Decor Film — ฟิล์มลวดลายไม้** |
| 10 | เพิ่มรายละเอียด **SPC Core — แกนกลาง SPC** |
| 11 | เพิ่มรายละเอียด **IXPE Backing — ชั้นรองพื้น IXPE** |
| 12 | แสดงภาพรวมครบทั้งสี่ชั้น จากนั้นเลื่อนต่อเข้าสู่ส่วนเลือกสีและทดลองภาพห้อง |

ในโค้ดใช้ดัชนีขั้น 0–11 จึงตรงกับขั้น 01–12 ที่ผู้ใช้เห็น เส้นคำอธิบายอ้างอิงตำแหน่งชั้นวัสดุที่ฉายจากฉาก 3D และปรับตามการหมุนกล้อง ผู้ใช้ยังลากเมาส์หมุนชิ้นตัวอย่าง ใช้ปุ่มก่อนหน้า/ถัดไป หรือเลือกจุดขั้นโดยตรงได้ ลิงก์ **เลือกสีพื้นด้านล่าง** ข้ามเรื่องราวไปยังส่วนถัดไปได้ทันที

เมื่ออุปกรณ์ตั้งค่า **Reduce Motion** หรือความสูง viewport ต่ำกว่า **580 พิกเซล** จะใช้ฉากแบบไม่ตรึงและไม่ผูกลำดับกับการเลื่อน ผู้ใช้กดปุ่มเลือกขั้นเพื่อดูสี ความหนา และรายละเอียดครบทั้ง 12 ขั้นได้ ส่วนหน้าที่เหลือยังเลื่อนได้ตามปกติ

**5 MM เป็นความหนารวมของชิ้นตัวอย่างหน้าแรกเท่านั้น** ชิ้นตัดแสดงโครงสร้างมีขนาด 600 × 300 มม. ระยะระหว่างชั้นถูกขยายเพื่ออธิบาย และเส้นความหนารวมแสดงขณะแผ่นยังประกบอยู่ ไม่ใช่ระยะช่องว่างหลังแยกชั้น ค่านี้ไม่ใช่การยืนยันสเปกการผลิตหรือความหนารายชั้นของสินค้าจริง และไม่เปลี่ยนข้อมูล 5.3 มม. ของ Material Studio เดิม

การจับคู่ข้างต้นอิงลักษณะสีและลายที่ใกล้เคียงเพื่อการแสดงผล ยังไม่ใช่แคตตาล็อกสินค้าที่รับรองชื่อรุ่นหรือรหัสจริง แสงในภาพอ้างอิงและในฉาก WebGL อาจทำให้สีต่างจากสวอตช์หน้าเว็บ

ภาพห้องใน Motion Scrolling และตัวอย่างห้องหน้าแรกเป็น **ภาพถ่ายพร้อม mask ที่วาดกำหนดไว้** ส่วนชิ้นตัวอย่างพื้นเป็น WebGL 3D จริง ห้องในส่วนเปิดหน้าไม่ใช่ห้อง 3D เต็มรูปแบบหรือระบบแยกพื้นอัตโนมัติ การเปลี่ยนสีปรับเฉพาะพื้นในภาพเดิม เก็บเฟอร์นิเจอร์ ผนัง หน้าต่าง ลายพื้น และเงาของภาพอ้างอิงไว้ พร้อมจำกัดแสงสว่างไม่ให้ลายไม้หายไปเมื่อเปลี่ยนเป็นสีอ่อน ปุ่มมุมภาพในส่วนทดลองห้องเป็นการครอป/ซูมภาพเดิม ไม่ได้สร้างมุมกล้องใหม่ ความละเอียดของห้องย่อยถูกจำกัดด้วยส่วนภาพจากต้นแบบ

ภาพอัปโหลดใช้พื้นที่สี่มุมที่ผู้ใช้เลือกและการวางลายไม้ตาม perspective จึงต้องเลือกส่วนพื้นโล่ง หากเลือกครอบเฟอร์นิเจอร์ ระบบไม่สามารถแยกวัตถุนั้นออกเอง สีและแสงเป็นภาพจำลองเพื่อช่วยเปรียบเทียบ ไม่ใช่การวัดสีวัสดุจริง

ชิ้น WebGL บนหน้าแรกเป็น **ชิ้นตัวอย่างตัดหน้าพื้นขนาด 600 × 300 มม.** เพื่อแสดงชั้นวัสดุ ไม่ใช่แผ่นขายเต็มขนาด ระยะห่างระหว่างชั้นขยายเพื่อให้อ่านโครงสร้างได้ ส่วน Material Studio เดิมยังใช้ข้อมูลขนาดผลิตภัณฑ์ของตน

ยังไม่มีระบบสมาชิก ฐานข้อมูลรับคำขอ ระบบชำระเงิน หรือบริการส่งอีเมลอัตโนมัติ การกดเตรียมอีเมลไม่ได้ส่งข้อความ ผู้ใช้ต้องตรวจและส่งในแอปอีเมลเอง ภาพอัปโหลดไม่ได้ส่งขึ้นเซิร์ฟเวอร์หรือเก็บถาวรโดยแอป

## รัน สร้าง และตรวจสอบ

ใช้ Node.js 22.12 ขึ้นไป จากโฟลเดอร์โครงการ:

```powershell
npm ci
npm run dev
```

เปิด `/website/` หรือ `/calculator/` บน URL ที่ Vite แสดง; โหมดพัฒนายังเปิด `/` และ `/room/` ได้

```powershell
npm run build:website
npm run preview:website -- --port 5185 --strictPort
```

เปิดอีกเทอร์มินัลเพื่อทดสอบเว็บไซต์ที่รันอยู่:

```powershell
npm run test:website
npm run test:story
```

ชุดทดสอบใช้ Chrome ผ่าน Playwright ค่า URL เริ่มต้นคือ `http://127.0.0.1:5185/website/` เปลี่ยนได้ด้วยตัวแปร `SPC_WEBSITE_URL` ผลและภาพหน้าจอของเว็บไซต์อยู่ใน `test-results/website/` และ Motion Scrolling อยู่ใน `test-results/story/` การทดสอบเรื่องราวครอบคลุมสีทั้งหก การย้อนลำดับ ชั้นวัสดุ เส้นคำอธิบาย การตรึง/ปล่อยหน้า การหมุนด้วยเมาส์ มือถือ และโหมดลดการเคลื่อนไหว ส่วน `npm test` ตรวจตรรกะ timeline รวมกับการทดสอบเดิมของ viewer

`build:website` ตรวจ TypeScript และสร้าง `website-dist/` สำหรับหน้าใหม่ 2 หน้า ส่วนเดโมเดิมสร้างแยกด้วย `npm run build` เป็น `demo-dist/` และ `npm run build:room` เป็น `room-dist/` การโฮสต์รวมต้องวางผลลัพธ์ให้เส้นทางทั้ง 4 เปิดได้ โดยรักษาโฟลเดอร์ assets ของแต่ละ build
ลิงก์และภาพของเว็บไซต์ใหม่ใช้เส้นทางจากรากโดเมน เช่น `/website/` จึงต้องปรับ URL หากโฮสต์ใต้ path prefix
