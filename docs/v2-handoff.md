# Coolplan V2 — Material Theatre

V2 เตรียมเป็นหน้าแยกที่ `/v2/` โดยออกแบบให้เชื่อมฉาก Spline กับหน้า HTML/CSS ที่แสดงภาพเปิดหน้าได้ก่อนฉาก 3D **ขณะส่งมอบนี้ยังเป็นงานในเครื่อง ไม่มี V2 ที่เผยแพร่สาธารณะ และยังไม่เชื่อมฉากเข้ากับหน้าเว็บ** หน้าเดิม `/website/`, `/calculator/`, `/room/` และ `/` ยังคงอยู่ ปุ่มเลือกพื้นและคำนวณราคาเชื่อมกลับไปยังฟังก์ชันเดิม

## สถานะจริงและข้อจำกัด

- สร้างหน้าเว็บ V2 และ source ของ HTML overlay แล้ว
- ฉาก Spline แบบภาพนิ่งถูกบันทึกในไฟล์ด้านล่าง แก้ไขต่อใน editor ได้
- `set_html_content` **ยังไม่ได้ทำงานสำเร็จ** จึงยังไม่มี overlay หรือ motion ของ V2 อยู่ในไฟล์ Spline
- overlay ผ่านการทดสอบกับ bridge จำลองในเครื่องเท่านั้น ยังไม่ได้ยืนยันกับ Spline runtime จริง
- `SPLINE_SCENE_URL` ยังเป็นค่าว่าง ยังไม่มี public export และยังไม่ได้ deploy V2
- ติดโควต้าเครื่องมือ Spline รายวันของแผน Free ที่ 20 ครั้ง ระบบระบุว่าจะรีเซ็ตเวลา **00:00 UTC / 07:00 น. เวลาไทย** ต้องรอโควต้าเพื่อใส่ overlay ตรวจฉากจริง และ export ต่อ
- `deliverables/coolplan-v2-preview.html` เป็น **ภาพรวมดีไซน์แบบ HTML ออฟไลน์** เปิดไฟล์ได้โดยไม่ต้องรันเซิร์ฟเวอร์ รวมภาพและฟอนต์ไว้แล้ว แต่ไม่มีฉาก WebGL หรือแอนิเมชัน Spline ที่ทำงานอยู่

## ฉากที่แก้ไขต่อได้

- ชื่อไฟล์ Spline: **Coolplan V2 — Material Theatre**
- File ID: `76e891c1-57e1-47fb-9f29-6559e1a96f10`
- วัตถุ วัสดุ แสง และกล้องแก้ไขต่อได้ใน Spline panel
- `src/v2/spline-scene.html` เป็น source HTML/JavaScript ของตัวควบคุมฉากและ Spline bridge ที่ **ยังรอนำส่ง** เข้าไฟล์ Spline
- `src/v2/config.ts` เก็บ `SPLINE_SCENE_URL` และ File ID ส่วน URL รอผู้ดูแลใส่ค่าจริงจากการ export ที่ตรวจสอบแล้ว ห้ามเดาหรือใช้ URL ของ editor แทน public export

เมื่อเชื่อม export แล้ว หน้าเว็บจะใช้ iframe เพียงหนึ่งตัว และไม่โหลด Three.js ของ V1 ซ้ำ การโหลดเอกสาร iframe อย่างเดียวไม่ถือว่าฉากพร้อม ต้องรอข้อความจาก bridge:

```js
{ type: 'coolplan:spline-ready', fileId: '76e891c1-57e1-47fb-9f29-6559e1a96f10' }
```

ข้อความนี้ใช้ปิดสถานะกำลังโหลดเท่านั้น ไม่มีสิทธิ์เปลี่ยน URL หรือเรียกโค้ด หากเตรียมฉากนานจะแสดงปุ่มลองอีกครั้ง ผู้ใช้ยังมีลิงก์เปิดฉากเต็มหน้าและปุ่มข้ามไปเลือกสีด้านนอก iframe

| ขั้น | เนื้อหา |

| 12 | ภาพรวมครบทุกชั้นและทางไปเลือกสี/คำนวณราคา |

พฤติกรรมที่เตรียมไว้คือการเลื่อนและปุ่มควบคุมภายในฉากเพื่อสำรวจลำดับ แต่ยังต้องทดสอบกับ Spline จริง ส่วนหน้าเว็บภายนอกใช้การเลื่อนปกติและมีทางข้ามฉาก สีเป็นภาพจำลองเพื่อเปรียบเทียบ ควรยืนยันกับตัวอย่างจริง ความหนารวม 5 มม. และภาพแยกชั้นเป็น **แผนภาพอธิบาย** ระยะห่างและขนาดแสดงผลขยายเพื่อให้อ่านง่าย ไม่ใช่การรับรองความหนาของแต่ละชั้นหรือสเปกสินค้าทุกรุ่น

## ไฟล์และการรัน

| ไฟล์ | หน้าที่ |
| --- | --- |
| `v2/index.html` | เนื้อหาหน้าเว็บ ลิงก์เดิมและข้อมูลติดต่อ |
| `src/v2/style.css` | รูปแบบเดสก์ท็อป/มือถือและ reduced motion |
| `src/v2/main.ts` | โหลด iframe เมื่อจำเป็น สถานะพร้อม ลองอีกครั้งและการเก็บทรัพยากร |
| `src/v2/config.ts` | public export URL และ Spline File ID |
| `src/v2/spline-scene.html` | UI และพฤติกรรมภายในฉาก Spline |
| `public/v2/assets/` | ภาพเปิดหน้าและตัวอย่างลายที่ปรับขนาดไฟล์แล้ว |
| `src/v2/prepare-assets.mjs` | เครื่องมือสร้างภาพย่อจากต้นฉบับ ต้องมี `sharp` หรือกำหนด `COOLPLAN_SHARP_RESOLVER` |
| `deliverables/coolplan-v2-preview.html` | แบบร่างดีไซน์ออฟไลน์ไฟล์เดียว ไม่มี Spline runtime |

```powershell
npm run build:v2
npm run preview:v2 -- --port 5202 --strictPort
```

เปิด `http://127.0.0.1:5202/v2/` ผล build อยู่ที่ `v2-dist/` ปัจจุบัน preview นี้ยังไม่เชื่อม Spline การเผยแพร่หลังเชื่อมและตรวจครบแล้วให้ merge ผล build เข้า static Site เดิมโดยเก็บทุก route และ asset เดิมไว้ ไม่แทนที่หรือล้างโฟลเดอร์เว็บทั้งหมด
